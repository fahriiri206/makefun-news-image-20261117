# 17 November 2026 — World News in One Image

A make.fun competition entry for the prompt **"Sum up 17 November's world news in one image"**.

The entry is a single 1024x1024 PNG (`entry.png`) that carries six stories from
**Tuesday 17 November 2026**. The image is committed separately beside this
README. `main.py` does not generate the image: it validates the committed PNG
and copies its bytes, unchanged, to the output path.

## How the program works

`main.py` targets Python 3.13 and uses only the standard library. It makes no
network calls and never modifies the image bytes.

1. **Locate the image.** It resolves its own path with `os.path.realpath` and
   looks for `entry.png` beside itself. If that file is absent it falls back to
   `/bot/entry.png`.
2. **Read the bytes once** into memory.
3. **Validate the PNG.**
   - Check the 8-byte PNG signature.
   - Reject files larger than 1,048,576 bytes.
   - Walk the chunk list: read every 4-byte length, the 4-byte chunk type, the
     payload, and the 4-byte CRC; recompute each CRC with `zlib.crc32` and
     reject any mismatch or truncated chunk.
   - Require `IHDR` to be the first chunk and `IEND` to be the last, with no
     trailing bytes.
   - Read width and height from `IHDR` and reject anything larger than
     1024x1024.
4. **Write the output.** The output directory is `MAKEFUN_OUTPUT_DIR` when set,
   otherwise `/output`. It is created with `os.makedirs(..., exist_ok=True)`,
   then the exact bytes are written with a single `open(..., "wb")`, flushed
   and fsynced.
5. **Report.** On success it prints one line with the output path, the byte
   count and the SHA-256 of the written bytes. On any failed check it prints a
   single line to stderr naming the failed check and exits non-zero.

Because the input bytes are copied verbatim, repeated runs are byte-identical.

## How to run

From the repository root:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The image is written to `out/entry.png`. Running it again into another
directory produces the same bytes:

```sh
mkdir -p out2 && MAKEFUN_OUTPUT_DIR=out2 python3 main.py
sha256sum entry.png out/entry.png out2/entry.png
```

In the competition container, `/bot` is read-only and `/output` is writable, so
no environment variable is needed:

```sh
python3 main.py
```
